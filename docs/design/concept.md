# video_reader 콘셉트 카드 (2026-11-24, 자율 진행 — 추천 시안 A로 정함, 사용자 확인 전. 평가 3회 반영)

콘셉트: **밀착 인화지(contact sheet)** — 영상 한 편이 인화지 한 장이다. 구간마다 그 구간의 칸 수만큼 잘린 필름 조각이 왼쪽에 놓이고, 옆에 그 구간의 정리가 적힌다.
왜 이 제품에: 사진가가 밀착 인화지를 보며 칸을 고르고 그리스 펜슬로 표시하듯, 이 제품은 "영상을 보지 않고 훑고, 필요한 칸만 확인·고치는" 일을 한다.
화면을 실제로 읽은 구간과 말만으로 정리한 구간의 차이가 이 제품의 핵심 가치(화면에만 있는 정보)이고, 그게 "현상된 칸 / 빈 칸"으로 바로 보인다.
인상: 차분한 작업 도구 + 사진 재료감 (스타일 0.35). 바탕은 라이트 테이블 회색, 그 위에 필름 보관함 판과 흰 인화지가 떠 있다.

층 (2026-11-25, 사용자 "레이어 느낌으로 … 공간감도 요소의 배치와 여백이 더 균형 있게"): ① 라이트 테이블(바닥) ② 떠 있는 판 둘 — 필름 보관함(넣기·목록, 필름과 같은 흑연 재료, 반경 12) / 인화지(결과, 반경 6) ③ 인화지 안 — 라벨 띠(조작층: 제목·메타·도구, 한 톤 어두운 면 + 아래 선) / 정리 본문(읽기층: 개요·구간) ④ 필름 조각(인화지 위 물건, 자기 그림자, 반경 3) · 뜬 것(뷰어·메뉴·알림).

평균 틀과 다른 점 (평균 = 왼쪽 영상 플레이어 + 오른쪽 탭[요약/스크립트/채팅] + 시각 칩 달린 글머리 목록, 작업 목록은 썸네일 카드 격자):
1. 플레이어가 주인공이 아니다 — 주인공은 세로 필름 띠 + 구간 정리. 원본은 시각을 누를 때만 작은 뷰어로 뜬다
2. 화면을 읽었는지가 구조에 들어간다 — 현상된 칸(실제 화면) / 빈 칸(말만) — 배지·아이콘으로 얹지 않는다
3. 작업 목록도 필름 — 영상마다 작은 띠가 정리된 만큼 칸이 채워진다 (진행률 막대 대신)

규칙:
1. 필름 위에는 영상에서 온 것만 — 화면 칸, 칸 번호(회색), 시각(가장자리 인쇄 색). 사람이 쓴 글·버튼은 인화지 흰 면에. 필름은 칸 수만큼의 조각 — 빈 필름을 늘이지 않는다 (최종 평가 1: 빈 검정 띠가 "깨진 레이아웃"). [지킴]
2. 시각은 어디서나 같은 모양(재생 표시 + 호박색 숫자)이고, 누르면 그 시각의 원본으로 간다. 시각이 아닌 것(로고·칸 번호)에 호박색을 쓰지 않는다. [지킴]
3. 빨강(그리스 펜슬)은 사람이 고친 것에만 — 고친 구간의 칸 번호 동그라미와 "고침". 오류는 빨강이 아니라 글로 말한다 (stt 카드 규칙 3과 같은 뜻). [지킴]
4. 진행 중인 것은 같은 띠 위에서 현상된다 — 아직 정리 안 된 구간은 점선 빈 칸, 정리되면 채워진다 (따로 만든 진행 화면 없음). [지킴]
5. 인화지는 한 장 — 개요·구간이 한 면에 이어지고, 묶음은 한 면 구분선으로. 판(보관함·인화지)과 필름 조각·뜬 것만 그림자, 안쪽은 간격·선. [지킴]
6. 판은 사물이다 — 인화지 머리의 영상 정보는 현상소 접수 라벨(칸마다 항목명 + 값), 필름 조각 아래는 밀착 인화지의 줄 번호 인쇄(구간 번호·길이·화면 장수), 보관함 목록의 작은 띠는 진짜 필름 조각(검정 바탕). (2026-11-25 평가: "층은 있는데 판이 사물로 안 보인다") [지킴]

데이터 매핑: 구간 → 필름 조각 / 화면을 읽은 칸 → 현상된 칸(실제 화면, 컬러) · 붙였지만 읽지 않은 칸 → 흑백으로 바랜 칸 · 말만 → 어두운 빈 칸에 시각 / 정리 안 된 구간 → 점선 칸 /
사람이 고친 구간 → 칸 번호 위 빨간 동그라미 / 작업 진행 → 목록 작은 띠의 채워진 칸 수 / 원본 시각 → 칸 아래 가장자리 인쇄.
